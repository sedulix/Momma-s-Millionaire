## #️⃣ About the Project
Momma's Millionaire is an online platform where users can practice financial skills, track their progress, and improve other useful abilities. It includes account management, interactive exercises, and analytics to help users grow their knowledge in a fun and engaging way.

---

## ✨ Features

🔐 **User Registration** <br>
Create a full account with secure storage in the database

💡 **Spending Recommendations** <br>
Get personalized advice on how to save money based on your expenses

📊 **Control Panel** <br>
Interactive sliders for:
- Savings rate  
- Lifestyle intensity  
- Debt focus
- And more!
  
🌐 **Real-World Data Mode** <br>
Pulls live data for:  
- Current inflation  
- Interest rates  
- Goverment expenses
- And more! 

🎮 **Simulator** <br>
Practice decision-making in a safe, interactive environment that simulates financial scenarios.

🤖 **AI Financial Advisor** <br>
Get intelligent advice and recommendations powered by AI to improve your financial decisions.

## ⚙️ Technologies
Frontend: HTML / CSS / JavaScript<br>
Backend: Python / Django / dotenv / OpenAI / Pillow / requests<br>
Database: PostgreSQL

## 🔧 Running the Project
```bash
git clone https://github.com/ScriptSlinger1/Momma-s-Billionaire.git
cd momma-s-millionaire

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt

python manage.py runserver
```
